# The consonant round's frozen look-half readings (#177)

Generated by `python -m training.consonant_readout freeze --half look` and `python -m training.consonant_readout doc` from `tools/tadabur/consonant_readout/freeze.json`; do not edit by hand.

**C95, look half only.** The confirm half was not read: the freeze command refuses `--half confirm`, and this record holds only the look half of Tarteel v1.

A **false flag** is a word the app shows as not correct on a clip of correct recitation. A word may carry more than one cause, so the causes can add up to more than the flagged words.

The causes are `training.word_flags`'s: `tashkeel` (a haraka mark the mushaf prescribes is missing or wrong); `soft_pair` (a consonant heard as its soft-pair partner; Muraja's soft-pair allowance forgives these); `target_pair` (a consonant heard as one of the target pairs (ذ↔ظ, س↔ش, ط↔ق); the app does not forgive these); `other_consonant` (any other consonant substitution, deletion included); `shaddah` (a doubled consonant collapsed into one); `skipped` (the app's skip marking passed the word over); `unrecorded` (the kept grade names no error, so the cause is unknown).
